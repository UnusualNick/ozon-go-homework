# Homework 1: console task tracker

Интерактивный консольный таск-трекер на Go. Программа читает команды из
`stdin`, хранит задачи в JSON-файле и завершает работу по команде `exit`.

Преподаватель персонально разрешил Илье использовать AI-ассистентов при
выполнении этой работы. Разрешение не является общим правилом курса.

## Возможности

- создание, просмотр, изменение статуса, редактирование и удаление задач;
- статусы `planned`, `in_progress`, `canceled`, `done`;
- сохранение данных между запусками;
- сортировка по дедлайну, затем по ID;
- понятные ошибки и валидация аргументов;
- регистронезависимый поиск, пагинация и импорт из JSON;
- слои `domain`, `storage`, `business`, `UI`; `main` только связывает их.

## Запуск

Требуется Go 1.24+.

```bash
go run ./cmd/task-tracker
```

По умолчанию данные сохраняются в `tasks.json` в текущей директории. Другой
путь можно передать через `-data`:

```bash
go run ./cmd/task-tracker -data ./var/tasks.json
```

## Команды

Аргументы с пробелами заключаются в кавычки. Дедлайн принимается в формате
`YYYY-MM-DD` или RFC3339.

```text
help
add "Подготовить отчёт" 2026-10-20
list
list --status planned --search отчёт --page 1 --limit 10
get 1
status 1 in_progress
edit 1 --title "Защитить отчёт" --deadline 2026-10-21
delete 1
import tasks-to-import.json
exit
```

Файл импорта — JSON-массив. Поле `id` необязательно: если оно отсутствует или
равно нулю, приложение назначит следующий свободный ID.

```json
[
  {
    "title": "Пример задачи",
    "status": "planned",
    "deadline": "2026-10-20T00:00:00Z"
  }
]
```
