# ДЗ 4: SQL и базы данных

Пять обязательных задач из выданного `hw4.md` решены в [solutions.sql](solutions.sql).
Это обычные запросы PostgreSQL: Go-код для основной части задания не нужен.
[testdata.sql](testdata.sql) повторяет схему и строки из условия, чтобы можно было
проверить запросы в отдельной пустой базе.

## Проверка

Создайте пустую тестовую базу PostgreSQL и выполните из корня репозитория:

```bash
psql -X -v ON_ERROR_STOP=1 -d ozon_hw4_test \
  -f homework-04/testdata.sql \
  -f homework-04/solutions.sql
```

Имя базы здесь пример: перед запуском её нужно создать самому или подставить
свою. Не запускайте `testdata.sql` в рабочей базе: он создаёт таблицы `users`
и `orders` с учебными данными.

На данных из условия получаются:

1. Борис и Вера — оба из Москвы, обоим по 40. Запрос возвращает *всех*
   пользователей с максимальным возрастом, а не случайного одного из них.
2. Москва — 3, Казань — 2.
3. Борис — 120000, Глеб — 57000, Анна — 51500, Егор — 38000,
   Вера и Дина — по 0. `LEFT JOIN` оставляет пользователей без заказов.
4. Глеб и Егор — по одному разу, несмотря на два заказа Егора с наушниками.
5. Наушники — 12000. Если минимальную подходящую цену имеют несколько
   заказов, выводятся все их строки, даже если товар и цена совпадают.

Бонусный метод `OldestInCity` для проекта `item` не входит в обязательные пять
запросов. Исходников `item` в этом репозитории нет, поэтому бонус здесь не
реализован; для него нужен сам проект с `internal/storage/storage.go`.
