# Домашние работы по Go для Ozon Tech

Преподаватель попросил 1 октября складывать работы в один репозиторий. У каждого
задания свой каталог и Go-модуль:

- [ДЗ 1](homework-01/) — консольный таск-трекер с файловым хранилищем;
- [ДЗ 2](homework-02/) — gRPC-сервис товаров и HTTP-корзина;
- [ДЗ 3](homework-03/) — тесты и параллельное чтение корзины поверх ДЗ 2.

Проверка из корня:

```bash
(cd homework-01 && go test ./... && go vet ./... && go build ./...)
(cd homework-02 && go test ./... && go vet ./... && go build ./...)
(cd homework-03 && make test-race && go vet ./... && make build)
```

ДЗ 1 и ДЗ 2 опубликованы, но в предыдущем учёте не было подтверждения отправки
преподавателю. Позже курс дал [форму для сдачи](https://t.me/c/3976611877/58);
не стоит путать публикацию репозитория с отправкой через неё. ДЗ 3 пока только
в локальной ветке `homework/03`: ничего из этой ветки не отправлено в форму и
не опубликовано на GitHub.
