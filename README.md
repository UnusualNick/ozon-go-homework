# Ozon Tech Go homework

Единый репозиторий домашних работ по курсу Ozon Tech Go, как попросил
преподаватель 1 октября 2026 года. Каждая работа находится в отдельном
каталоге.

## Работы

- [`homework-01/`](homework-01/) — интерактивный консольный таск-трекер с
  файловым хранилищем, поиском, пагинацией и JSON-импортом;
- [`homework-02/`](homework-02/) — сервис товаров по gRPC и HTTP-сервис
  корзины.

У каждой работы собственный Go-модуль и README с командами запуска и
проверки. Из корня можно проверить обе работы последовательно:

```bash
(cd homework-01 && go test ./... && go vet ./... && go build ./...)
(cd homework-02 && go test ./... && go vet ./... && go build ./...)
```
